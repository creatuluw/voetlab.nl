# Canonical repo location and gitignore policy

The `voetlab` framework (working dir `voetlab.nl/`) is now hosted at
**https://github.com/creatuluw/voetlab.nl** on the `main` branch, under the
`creatuluw` account. The repo was initialized from a non-git tree and pushed as
a single commit of 131 files.

## `.gitignore` policy — what counts as regenerable here

`.gitignore` excludes regenerable build/test artifacts, machine-local state, and one size-limited binary-asset dir. Source code is never ignored; data is ignored only when a file would bust a size limit:

- `__pycache__/` — compiled Python bytecode
- `.pytest_cache/` — pytest run cache
- `*.egg-info/` — editable-install metadata (`voetlab.egg-info/`), regenerated by `pip install -e .`
- `tests/out/` — per-feature inspectable artifacts dumped by the footage-driven tests; regenerated on every `pytest` run
- `.pi/` — pi coding-agent session/config state for this project (todos, etc.); machine-local, never shared across machines
- `voetlab/external/tvcalib/data/` — the ~467 MB TVCalib calibration checkpoint; excluded on **size** (exceeds GitHub's 100 MB limit), not reproducibility — see [[rules/gitignore-large-checkpoints-document-the-download-instead]]

Rationale: every excluded path is reproducible from the tree itself, so the
commit stays clean of machine-local state. `docs/` (including the build guide,
dev log, raw transcript, generated HTML site, and this OKF wiki) is tracked,
along with the full `voetlab/` package and `tests/` source.
